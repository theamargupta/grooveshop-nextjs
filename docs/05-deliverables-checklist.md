# 05 — Deliverables Checklist

Tick only when the EFFECT is verified (Rule 7), not when a file merely exists.

- [ ] Next.js app runs (`pnpm dev`) — core flow: home → listing → detail → cart → checkout
- [ ] Unit tests pass (`pnpm test`)
- [ ] Coverage report generated → `docs/reports/coverage/` (state the % honestly)
- [ ] Playwright E2E pass (`pnpm test:e2e`)
- [ ] E2E **video** saved → `docs/reports/e2e-video/`
- [ ] Security audit written → `docs/reports/security-audit.md` (npm audit output + findings)
- [ ] Prompts log complete → `docs/04-prompts-log.md`
- [ ] README: scope, what's in/out and WHY, how to run, how to read reports
- [ ] 15–20 min screen recording of the agentic journey
- [ ] Public GitHub repo created, pushed (Amar approves)
- [ ] Final email sent with repo URL (Amar approves)

## No-IP check before pushing public

- [ ] No previous-employer code, names, or client data anywhere (code, tests, prompts, commits)
- [ ] `.env` / secrets git-ignored; no tokens in history
